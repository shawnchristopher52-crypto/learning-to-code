# 📚 Curated Resources

> Supplementary materials for when you want to dig deeper, see something explained differently, or just need a break with something more visual.

This is a *short* list on purpose. The internet has infinite tutorials and you can drown in them. The resources here have been chosen because they're high-quality and cover what we cover, well.

**You do not need to use any of these to finish the curriculum.** Use them when you want a second perspective on a topic.

---

## For Beginners (Phases 1–2)

### Free, beginner-friendly

- **Python's official tutorial** — https://docs.python.org/3/tutorial/
  *Surprisingly readable. Worth dipping into when you finish Phase 2 to see what's covered "officially."*

- **Automate the Boring Stuff with Python** — https://automatetheboringstuff.com/
  *Free online. Practical, project-driven. Great companion reading to Phases 1–2.*

- **freeCodeCamp YouTube channel**
  *Multi-hour tutorials on basically every topic. The "Learn Python — Full Course for Beginners" video is excellent if you want a parallel video walkthrough.*

### When you're ready to pay (or check the library)

- **Python Crash Course** by Eric Matthes — A clear, project-based book. Good Phase 2 companion.
- **Think Python** by Allen Downey — Free PDF online; more "computer-sciencey" perspective.

## For CS Fundamentals (Phase 3)

- **Grokking Algorithms** by Aditya Bhargava — The friendliest algorithms book that exists. Highly recommended.
- **Visualgo** — https://visualgo.net/ — Interactive visualizations of every data structure and algorithm we cover.
- **Big-O Cheat Sheet** — https://www.bigocheatsheet.com/ — A quick reference for time/space complexity.

## For Web Development (Phases 4–5)

- **MDN Web Docs** — https://developer.mozilla.org/
  *The single best reference for HTML, CSS, and JavaScript. Bookmark this. You'll use it weekly for the rest of your life.*

- **CSS Tricks** — https://css-tricks.com/
  *When you can't figure out a CSS layout, search "css tricks <thing>" and you'll usually find the answer.*

- **The Odin Project** — https://www.theodinproject.com/
  *Free, comprehensive web dev curriculum. If you want a parallel path for the web parts, this is the gold standard.*

- **JavaScript.info** — https://javascript.info/
  *The clearest deep-dive on JavaScript that exists, free.*

## How to Use Documentation (a Skill)

Reading documentation well is a superpower. Here's the secret most beginners don't know:

**You don't read docs from start to finish.** You search them, scan them, and read only the part you need. A good developer spends a lot of time in docs but reads them like a recipe book — find the page, follow the steps, close the book.

Try it now: skim the Python docs page for `print` — https://docs.python.org/3/library/functions.html#print

It's denser than a tutorial, but notice how it gives you exact information. As you grow, you'll lean on docs more and tutorials less.

## Communities (Use With Care)

When you want to talk to other beginners or developers:

- **r/learnpython** on Reddit
- **r/learnprogramming** on Reddit
- **The Programmer's Hangout Discord** (search for it; lots of friendly developers, channels for every topic)

**One word of warning:** spending too much time *talking* about coding is a known trap. Building beats discussing, every time. Use communities for help when stuck, not as a substitute for practice.
