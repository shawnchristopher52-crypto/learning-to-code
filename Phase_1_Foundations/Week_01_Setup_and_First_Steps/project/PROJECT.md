# Week 1 Project: A Personal "About Me" Greeter

> **Goal:** Combine everything you learned this week into a single, friendly little program.

---

## What You're Building

A Python program (`about_me.py`) that prints a multi-line introduction about yourself when run. Think of it as a digital business card.

When someone runs your program, they should see something like this (with your real info, of course):

```
================================
   Hi, I'm Chris Christy.
================================

About me:
- I am learning to code from scratch.
- My goal is to become a full-stack developer.
- I am currently in Week 1 of my journey.

Today's bit of math, just because:
- 12 months × 8 hours/week × 4 weeks/month = 384 hours of practice ahead.

Thanks for stopping by!
```

That's the target. Yours can have any content you want — make it personal.

---

## Requirements

Your program must:

1. Use **at least 8** `print()` calls
2. Include **at least one math expression** that gets printed (use `print(some_math_here)` style, no quotes)
3. Include **a string with quotes inside it** (force yourself to handle the quote-inside-quote situation from Exercise 1D)
4. Use **at least one decorative line** (made of `=`, `-`, or `*` characters) to add visual structure

---

## Stretch Goals (Optional)

If the basic version felt easy, try one or more of these:

- **Use blank lines** to separate sections (a `print()` with empty quotes prints a blank line: `print("")` or just `print()`)
- **Multiply a string** to make decorative borders: `print("=" * 30)` prints 30 equals signs
- **Compute something meaningful** — like how many days are between your birthday and the end of the year (you can hardcode the number for now; we'll get fancier with dates in Phase 2)

---

## How to Build It (Suggested Approach)

Don't write all 30 lines at once. Build it up gradually. This is how real developers work — small steps, checking at each one.

1. Create the file: in VS Code, in the `project` folder, create `about_me.py`.
2. Start with one line: `print("Hi, I'm <your name>.")`. Save. Run it. See it work.
3. Add the next line. Save. Run.
4. Keep adding sections. Run frequently. **Running often catches mistakes early.**
5. Once it looks how you want, give it a final read-through. Polish the wording.

This habit — small change, save, run, repeat — is the most valuable habit a beginner can build. We'll formalize it later as the "edit-test loop." For now, just notice how good it feels to see your program grow.

---

## After You Build It

1. Save the final version.
2. Add it to Git: `git add about_me.py`
3. Commit it: `git commit -m "Add Week 1 project: about_me.py"`
4. Push: `git push`
5. Visit your GitHub repo and admire it. Your file is now public on the internet.
