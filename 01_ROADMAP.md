# 🗺️ The Full Roadmap

> Day 0 beginner → Independent developer in ~12 months at 6–10 hrs/week

This document is your **map of the entire journey**. You don't need to memorize it. Just glance at it now to see the shape of where you're going, and refer back when you finish a phase to feel the progress.

---

## The Philosophy

This curriculum is built on three principles drawn from how the best universities and self-taught developers actually learn:

**1. Build, build, build.** Every concept is followed by a project. Reading about code without writing it is like reading about swimming without getting wet. We weight heavily toward hands-on work.

**2. Strong foundation before frameworks.** Frameworks come and go. Computer science fundamentals (how data is organized, how algorithms work, how memory and networks behave) last your entire career. We invest in foundations early so the rest sticks.

**3. Public portfolio from Day 1.** Every project you build goes on GitHub. By the time you finish, you have a public record of growth that's worth more than any certificate. Employers, collaborators, and future-you will all benefit.

## Phase 1 — Foundations (Weeks 1–4)

**Goal:** Set up your tools, understand what programming actually *is*, and write your first working programs.

| Week | Topic | Project |
|------|-------|---------|
| 1 | How computers think + environment setup (Python, VS Code, Git, GitHub) | "Hello, World" + your first GitHub commit |
| 2 | Variables, data types, basic operations, getting input | A unit converter (temperature, length, weight) |
| 3 | Conditionals (if/else), comparing data, decision-making | A text-based "choose your own adventure" game |
| 4 | Loops, working with collections, basic problem-solving | A simple budget tracker |

**By end of Phase 1:** You'll have written ~500 lines of Python, made multiple GitHub commits, and built 4 small but real programs.

---

## Phase 2 — Python Mastery (Weeks 5–12)

**Goal:** Become genuinely fluent in Python. Stop having to think about syntax and start thinking about *problems*.

| Week | Topic | Project |
|------|-------|---------|
| 5 | Functions, scope, parameters, return values | A reusable math/utilities library |
| 6 | Lists, dictionaries, sets, tuples (data structures, part 1) | A contact book (CRUD operations) |
| 7 | Strings, file I/O, working with text data | A log file analyzer |
| 8 | Modules, packages, virtual environments, pip | Build & publish a small package |
| 9 | Object-Oriented Programming (classes, inheritance) | A library checkout system |
| 10 | Error handling, debugging, testing basics | Re-do an earlier project with full tests |
| 11 | Working with APIs, JSON, HTTP requests | A weather CLI tool that calls a real API |
| 12 | **Capstone project:** A full Python application of your choice | Personal project (we design it together) |

**By end of Phase 2:** You can build complete Python applications, structure them properly, test them, and use third-party packages. **First major portfolio piece.**

## Phase 3 — CS Fundamentals (Weeks 13–20)

**Goal:** Build the deeper understanding that separates "someone who can code" from "someone who can engineer software." This is the part most bootcamps skip.

| Week | Topic | Project |
|------|-------|---------|
| 13 | How code actually runs: memory, the stack, the heap, Big O notation | Algorithm visualizer (Python + simple graphics) |
| 14 | Recursion, divide-and-conquer thinking | Maze solver |
| 15 | Searching algorithms (linear, binary) | Search benchmark tool |
| 16 | Sorting algorithms (bubble, merge, quick, etc.) | Visual sorting comparison |
| 17 | Linked lists, stacks, queues | Browser history simulator |
| 18 | Trees & binary search trees | File system browser |
| 19 | Hash tables & graphs (intro) | Word frequency analyzer + simple graph traversal |
| 20 | Problem-solving practice (LeetCode-style problems, lots of them) | A solved-problems repo on GitHub |

**By end of Phase 3:** You think about code differently. You can analyze efficiency, choose the right data structure, and reason about complex problems. **This is where you stop being a beginner.**

## Phase 4 — Web Frontend (Weeks 21–28)

**Goal:** Build websites and web applications that anyone can visit in a browser.

| Week | Topic | Project |
|------|-------|---------|
| 21 | How the web works (HTTP, browsers, servers); HTML basics | Your first webpage |
| 22 | HTML deeper (forms, semantics, accessibility) | A multi-page personal site |
| 23 | CSS fundamentals (selectors, the box model, colors, typography) | Style your personal site |
| 24 | CSS layout (Flexbox, Grid, responsive design — mobile-first) | Responsive landing page |
| 25 | JavaScript fundamentals (variables, types, control flow — but in JS) | Interactive widgets (clock, calculator) |
| 26 | The DOM, event handling, dynamic web pages | A to-do list app (no framework) |
| 27 | Modern JavaScript (ES6+, async/await, fetch, modules) | Weather app that calls a real API |
| 28 | **Capstone:** Your personal portfolio website | Live, deployed portfolio site |

**By end of Phase 4:** You have a real, deployed personal website (your portfolio!) and can build any static or lightly-interactive site from scratch. **Major portfolio piece — and now your portfolio has a home.**

## Phase 5 — Web Backend (Weeks 29–36)

**Goal:** Build the *server side* of web applications — databases, user accounts, APIs, deployment.

| Week | Topic | Project |
|------|-------|---------|

**By end of Phase 5:** You can build complete web applications end-to-end — frontend, backend, database, deployment. **You are a full-stack developer.**

## Phase 6 — Modern Stack + AI Integration (Weeks 37–48)

**Goal:** Learn the tools the industry actually uses today, integrate AI into your work, and build a capstone you'd be proud to show in a job interview.

| Week | Topic | Project |
|------|-------|---------|
| 37 | React fundamentals (components, JSX, props) | Convert one of your earlier sites to React |
| 38 | React state, hooks, effects | A real-time dashboard |
| 39 | React Router, larger app architecture | Multi-page React app |
| 40 | Connecting React to your Flask API (full-stack with separate front/back) | Refactored task manager: React + Flask |
| 41 | Working with the Anthropic API / OpenAI API | Build an AI-powered tool |
| 42 | Designing AI features into apps (RAG basics, structured output, prompts) | An AI-augmented version of an earlier project |

| 45 | System design basics, scaling considerations | Architecture diagram + write-up of one of your projects |
| 46–48 | **Final Capstone:** A polished, AI-integrated, full-stack web app | Your "show this in interviews" project |

**By end of Phase 6:** You're a working developer. You can build modern, AI-integrated full-stack applications, deploy them, test them, and reason about them at a system level. **Final capstone is the centerpiece of your portfolio.**

## What "Done" Looks Like

When you complete this curriculum, you will have:

- **8–10 GitHub projects**, each with proper documentation
- **A live personal portfolio site** showcasing your work
- **At least one full-stack capstone** with AI integration
- **Comfort with Python and JavaScript** as production languages
- **CS fundamentals** that let you learn anything next: Go, Rust, mobile dev, data science, AI/ML — your choice
- **The mindset of a developer**: comfort with errors, debugging instincts, the patience to read documentation, the ability to break down problems

You will not "know everything." Nobody does. But you'll know how to *figure out* anything, and that is what matters.

---

## A Note on Pace

This roadmap is a target, not a contract. Some weeks may take you 4 days; others may take 10. The CS fundamentals phase (Phase 3) often takes longer for everyone — that's normal.

What matters is the loop: **read → try → build → reflect → commit.** Repeat that, week after week, and you'll get there.
